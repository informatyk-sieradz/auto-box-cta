Simple plugin that automatically adds customizable CTA boxes below WordPress posts.

== Description ==

Auto CTA Box allows you to display fully customizable CTA sections below blog posts.

Features:
- Custom CTA title
- Custom description
- Custom button text
- Multiple languages
- Hover animations
- Font size controls
- Color customization
- Responsive design

== Installation ==

1. Upload plugin folder to /wp-content/plugins/
2. Activate plugin
3. Go to Settings > Auto CTA Box

== Frequently Asked Questions ==

= Can I customize colors? =

Yes, you can customize colors, font sizes and CTA content.
