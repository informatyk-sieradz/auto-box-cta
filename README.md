# Auto CTA Box - Smart Marketing Automation for WordPress

**Auto CTA Box** is an advanced, lightweight WordPress plugin designed to automatically insert highly customizable Call-To-Action (CTA) boxes into your blog posts. It empowers website owners, SEO specialists, and digital marketers to scale conversion rates by dynamically matching specific CTA offers with post categories.

Eliminate the tedious process of manually editing hundreds of old articles. Define your rules once, and let the automation handle the rest.

---

## 🚀 Key Features

- **Automated Intelligent Insertion:** Automatically inject CTA boxes at the top, middle, or bottom of your articles (or all positions simultaneously).
- **Contextual Category-Based Targeting:** Show highly relevant CTAs based on WordPress post categories (e.g., articles in the "SEO" category promote an SEO Audit, while posts in "Google Ads" offer Ad Consultations).
- **Dynamic Live Preview:** Customize background colors, typography, buttons, margins, and border-radios with a real-time visual preview right inside the WordPress admin dashboard—no CSS knowledge required.
- **Built-in Click Analytics:** A lightweight, performance-optimized tracking system that counts clicks for both global and category-specific CTAs, helping you easily measure CTR and identify top-performing content.
- **Multilingual Support out of the Box:** Localization readiness for English, Polish, German, French, Spanish, and Russian.

---

## 🛠️ Architecture & Performance Focus

- **Clean WordPress Hook Integration:** Filters content via native hooks (`the_content`), ensuring compatibility with popular themes and block editors without bloating the database.
- **Asynchronous Click Tracking:** Leverages secure WordPress AJAX handlers to track clicks seamlessly without affecting frontend page load speeds (crucial for Core Web Vitals).
- **Vanilla JS/CSS Live Customizer:** Zero jQuery dependencies for the live preview engine, making the backend dashboard incredibly fast and responsive.
